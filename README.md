## Overview

Party Limit Begone removes Baldur's Gate 3's hard-coded four-character party limit, allowing players to bring any number of companions on their adventure simultaneously. Supporting solo, multiplayer, and custom party configurations, it enables truly large-party roleplay, tactical experiments with full companion rosters, and unique challenge runs without arbitrary size restrictions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Party Limit Begone** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Unlimited Party Size** | Bring as many companions as you want without the four-member cap |
| **Multiplayer Support** | Works correctly in both solo and multiplayer cooperative sessions |
| **Full Companion Access** | All origin and non-origin companions joinable simultaneously |
| **Tactical Flexibility** | Experiment with large party compositions for unique strategic builds |
